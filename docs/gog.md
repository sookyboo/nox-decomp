How to download `setup_nox_2.0.0.20.exe` from gog.com

## Installer extraction layouts

The launchers accept `setup_nox*.exe`, including both the older `setup_nox_2.0.0.20.exe` and newer `setup_nox_1.2_gog_v2_(93536).exe` installer. The older installer extracts an `app/` directory under `gamefiles/`; the newer installer places `gamedata.bin` and the game files at its extraction root. Launchers extract to a temporary directory and merge the output into `gamefiles/` for the older layout or `gamefiles/app/` for the newer layout. Existing files in those destinations are retained.
